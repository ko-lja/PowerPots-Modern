A modern port of [FTB PowerPots](https://github.com/FTBTeam/FTB-Power-Pots), currently only for 1.20.1 but may be ported to 1.21.1 and 26.1 soon(probably).

## What changed from the original?

Not much, mostly some QoL and fixes:

- Added some tooltips describing what they do and how they work
- Added base recipes for all pots
- Some misc code improvements
